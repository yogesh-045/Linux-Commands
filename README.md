## 🛡️ Linux for SOC Analysts

Linux is widely used in cybersecurity environments, servers, cloud infrastructure, SIEM systems, security tools, and incident-response workflows.

Some examples of SOC-focused Linux activities covered in this repository:

### 🔍 Log Investigation

```bash
grep "Failed password" /var/log/auth.log
```

### 👀 Real-Time Log Monitoring

```bash
tail -f /var/log/auth.log
```

### 🌐 Network Investigation

```bash
ss -tuln
```

### 🔎 DNS Investigation

```bash
dig example.com
```

### 🖥️ System Information

```bash
uname -a
```

### 🔐 Remote Investigation

```bash
ssh username@remote_ip
```

### 📁 Secure File Transfer

```bash
scp report.txt username@remote_ip:/home/username/
```
